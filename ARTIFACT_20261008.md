## Verify frozen evidence

Use Python 3.9 and install the pinned dependencies:

    python3.9 -m venv work/venv
    work/venv/bin/python -m pip install -r requirements-research-lock.txt
    sh reproduce_20261008.sh --check

The check mode verifies the manifest when present, all source/input hashes,
the complete dataset-root-method-budget-repeat matrices, bound consistency,
root-selection reachability/outdegree evidence, and the regression suite.
It also verifies the frozen manuscript, its 66-reference citation provenance,
the title/notation/heading consistency and key claims recomputed from raw
records by audit_manuscript_consistency_20261009.py,
the citation identity audit updated on October 12 by audit_citations_20261010.py,
and the PDF/source hashes recorded in the paper audit. This source/hash check
does not need a TeX installation or PDF Python packages.
It does not overwrite frozen records, figures, or the manuscript. The included
SpeedSteiner binary targets macOS ARM64, which is required for the frozen
native-binary regression tests. On another platform, run
`python verify_artifact_20261008.py` to check frozen evidence without executing
that binary, then use a separate copy for a full native rebuild and tests.

## Data and provenance

The package includes the frozen processed Bitcoin Alpha/OTC graphs, the 100K
Citi Bike sample, its recorded-duration transform, and three 100K NYC TLC
weight variants, and complete CollegeMsg/email-Eu-core histories. Raw monthly
ZIP/Parquet files are not bundled. Each processed
graph stores its official source URL, raw file hash, filters, and deterministic
bottom-k hash-sampling rule. The converters are included for regeneration from those sources.

Citi duration is recorded elapsed ride time; Citi haversine displacement is a
derived geographic proxy. TLC duration, miles, and total amount are recorded
fields, with positive finite values retained. Bitcoin penalties are derived
from signed ratings, and Bitcoin edges use a synthetic one-second duration.
The two additional communication histories have no recorded edge weights;
unit costs and one-second durations support structural comparisons only.
Their official downloads and all dataset-page citations are documented in
snap_provenance_20261008.json and the manuscript's single dataset table.
These are offline temporal-connectivity workloads, not dispatch,
capacity, vehicle, or inventory models.

Roots are selected from the 20 highest edge-outdegree vertices by descending
temporal reachability, descending outdegree, and lexical ID. The rule is
structure-only and frozen before the final reruns. Earlier exploratory
outcomes were known, so it is not an independent prospective preregistration.
The exact suite uses the first selected Citi root and first two TLC roots;
Bitcoin exact roots remain those from the earlier frozen suite.

## Method and claim boundaries

- Fixed-parent Cascade DP is exact within its defined temporal neighborhood.
  Large-graph hub/parent caps restrict which neighborhoods are inspected.
- A final no-improvement star round establishes convergence. Exhausting a
  round cap does not; the two experiments are reported separately.
- The Ikuta baseline uses the full edge/prefix model and a validated native
  HiGHS MIP start. Root precuts are separated before branch-and-bound. The
  original CPLEX node-callback implementation is not reproduced.
- Restricted-ILP dual bounds remain restricted. Only full-graph or
  safely equivalent ILP bounds enter global gaps.
- Time budgets are nominal end-to-end targets; actual solver and validation
  overruns remain in the records and paper.
- Timing repeats and roots from one graph are correlated. Paired outcomes
  are descriptive; no independence-based significance claim is made.
- Deadline-prefix cuts are weaker projections of established state cuts,
  retained as a negative audit rather than a novelty claim.
- Floating-point lower bounds use conservative margins, not exact rational
  certificates.

SpeedSteiner author code is frozen from
https://github.com/Guangyi-Zhang/directed-steiner-tree-code at commit
4191b7cf54b9310f065540dd80fc587aeefd3033. Its MIT license and the fmt and
Boost license files are bundled. The adapter uses the authors' fast_level2;
original edge weights are recomputed in double precision after validation.
The frozen adapter guard is 50,000,000 states times terminals.

Partial runs, historical experiments, local virtual environments, raw source
downloads, TeX logs, and machine-specific caches are excluded from the package.
The package manifest hashes every bundled file except itself.
The unchanged Boost headers contain one generic cache-path example; the
manifest records its narrow exemption from author-path detection.
